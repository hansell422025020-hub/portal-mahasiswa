## Implementasi yang digunakan
- Object Oriented Programming
- Session
- GET and POST protocol
- Array sebagai pengganti database sementara

## Fitur
- Autentikasi Login dan Logout dengan session
- Tabel untuk melihat masing-masing mata kuliah
- Fitur detail mata kuliah untuk melihat nilai dan predikat secara detail

## Teknologi
- PHP
- HTML
- CSS
- Javascript
- Github

## Cara Menjalankan
1. Clone repository.
2. Simpan di folder htdocs (atau folder tertentu tergantung local environment yang digunakan).
3. Jalankan Apache.
5. Buka project melalui browser.
